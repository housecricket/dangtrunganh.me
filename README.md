# dangtrunganh.me

Trang giới thiệu cá nhân dạng link-in-bio (tiếng Anh), một file HTML tĩnh, không cần build.

- `index.html`: toàn bộ trang (chữ, link, CSS).
- `cover.jpg`: bìa sách bản tiếng Anh. `og.jpg`: ảnh xem trước khi chia sẻ link.
- `vercel.json`: chuyển hướng 301 mọi link sách cũ (`/chuong/…`, `/en/…`, `/trich/…`, `/so-tay/…`…) sang `www.thelast10book.com`, giữ nguyên đường dẫn, để link cũ đã đăng trên LinkedIn vẫn mở đúng chương.

Sửa chữ: mở `index.html`, tìm đoạn cần đổi, sửa rồi push.
